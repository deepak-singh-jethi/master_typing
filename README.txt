Typing Master — Phase 5

A local-first adaptive typing application using React, Vite, Tailwind CSS, Supabase, IndexedDB, and compact LocalStorage persistence.

Setup:
  npm install
  npm run check
  npm run dev

The configured .env.local file is already included. Never replace the publishable frontend key with a Supabase service-role key.

Phase 5 adds a simplified dashboard, two-step onboarding, clearer practice setup, mobile-first typing ergonomics, focused results, global offline/sync feedback, accessible charts, route announcements, skip links, and a recoverable application error boundary.

See PHASE_5.md and VALIDATION.md for details.
